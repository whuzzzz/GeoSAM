# Model weights

Model checkpoints and DINOv3 weights are intentionally excluded from Git history. Place them in this directory (or pass an explicit `--ckpt` path) before running inference. The DINOv3 backbone wrappers use the relative paths documented in the top-level README; edit those wrappers if your installation uses a different layout.

A public checkpoint download link will be added here with the camera-ready release. Do not commit private experiment logs or checkpoints.
